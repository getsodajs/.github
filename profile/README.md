# Soda

A class-based web framework for [Bun](https://bun.sh): modules, dependency injection, controllers, guards, interceptors and filters, written with standard TC39 decorators and compiled into Bun's native router.

```bash
bun create soda my-app
```

- [Documentation](https://getsodajs.github.io/)
- [`@getsoda/core`](https://www.npmjs.com/package/@getsoda/core) on npm
- [HTTP benchmark](https://github.com/getsodajs/soda/tree/main/bench/http) against Bun, Hono and Nest

Soda is in early development (0.x): the API may change between minor versions.
